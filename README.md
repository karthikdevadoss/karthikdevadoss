## How I use AI in software engineering

I use AI where reasoning and generation create value:

- requirement interpretation
- repository investigation
- implementation planning
- candidate code generation
- incident diagnosis
- documentation and evidence summarization

I do **not** treat the model as the authority for:

- authorization
- test pass/fail
- deployment truth
- production correctness
- business invariants
- cost arithmetic

Those are verified using deterministic software, runtime evidence and human approval where required.
